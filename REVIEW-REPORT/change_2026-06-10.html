Cell 2 App Selector Changes

Root-level folder selection

Each folder listed directly under BASE_PATH now has a Root checkbox next to the expand control. Selecting this checkbox adds the root folder itself to TARGET_APPS.

Selection TARGET_APPS tuple Example
Root folder ("", folder_name, BASE_PATH/folder_name) ("", "Q2", "2026 Entitlement Review/Q2")
Child folder (parent_name, app_name, BASE_PATH/parent_name/app_name) ("Q2", "Application A", "2026 Entitlement Review/Q2/Application A")

Select Grey behavior

Expanded parent folders now show Select All and Select Grey controls. Grey folders are folders with a child count of 5 or more. Red folders are folders with a child count below 5.

Control Behavior
Select All Selects or clears every child folder under that parent.
Select Grey Selects or clears only grey child folders. Red child-folder selections stay unchanged.
Operator note: If a red folder was manually selected before using Select Grey, it remains selected. If a red folder was not selected, it remains unselected.

Root App Display and Manual Notes

Root-level selections use an empty category value. To avoid labels such as > Q2, the notebook now formats app keys with a shared helper:

Input Displayed key
category="", app_name="Q2" Q2
category="Q2", app_name="Application A" Q2 > Application A

The same formatting is used by dashboard grouping and Stage 7 reminder-email preparation, so manual note lookups and email app classification stay consistent.

Cell 7 Email Data Fix

Stage 7 continues to build reminder emails from pending rows only. The data preparation now protects pending rows from being dropped when folder_url is missing, blank, or null.

  • Missing folder_url values are normalized to #.
  • The grouping operation uses dropna=False.
  • Completed rows remain excluded from reminder emails.
  • Existing skip rules remain unchanged: Force Completed, N/A, Mark Done, Waived, and Escalated.
